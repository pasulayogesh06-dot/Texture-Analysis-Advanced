# Validation notes

Automated packaging checks:
- Python syntax compilation for `app.py` and all `src/*.py` modules.
- Smoke tests for enhancement, filtering, edge detection, segmentation, Fourier spectrum, GLCM, LBP, Gabor, HOG and PSNR/SSIM/MSE.
- PDF report byte generation.

Interactive Streamlit browser testing is environment-dependent and must be completed after installing requirements on the target Windows machine.
